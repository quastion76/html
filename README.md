# 링크 월드컵

이미지와 외부 사이트 링크를 함께 확인하면서 1:1로 후보를 고르는 정적 웹앱입니다.

## 기능

- 후보 이름 / 이미지 URL / 사이트 URL 등록
- 후보 카드 클릭으로 승자 선택
- `사이트 보기` 버튼은 선택 처리 없이 새 탭으로 열림
- 시작할 때 무작위 대진 생성
- 홀수 후보는 자동 부전승
- 라운드 자동 진행 및 최종 우승 표시
- 선택 기록 표시
- 진행 중인 게임을 `localStorage`에 저장하여 새로고침 후 이어하기
- 모바일 화면 대응

## 사용 방법

`index.html`, `styles.css`, `app.js`만 사용하는 순수 정적 사이트라 별도 빌드가 필요하지 않습니다.

### GitHub Pages

저장소의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`로 선택하고 `main / (root)`를 지정하면 정적 사이트로 공개할 수 있습니다.

## 후보 등록

웹페이지의 `후보 관리` 메뉴에서 직접 후보를 등록할 수 있습니다. 예시 후보는 데모용이므로 실제 사용 전 삭제하거나 교체하면 됩니다.

각 후보는 다음 정보로 구성됩니다.

```text
이름: 대부도 OO펜션
이미지: https://example.com/image.jpg
사이트: https://example.com/pension
```

후보 정보는 현재 브라우저의 `localStorage`에 저장됩니다.
